# Linux Basics Assignment

This repository contains my completed Linux Basics assignment submission.

## Files Included

- `Linux_Basics_Assignment_Submission.md` - assignment document with commands and explanations
- `assignment_commands.sh` - all Linux commands used in the assignment
- `screenshots/` - screenshots for each task

## Topics Covered

1. Creating and renaming files/directories
2. Viewing file contents using `cat`, `head`, and `tail`
3. Searching for patterns using `grep`
4. Zipping and unzipping files
5. Downloading files using `wget`
6. Changing permissions using `chmod`
7. Working with environment variables using `export`
