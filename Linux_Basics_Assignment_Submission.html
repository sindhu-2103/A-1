DevOps Assignment: Linux Basics

1. Creating and Renaming Files/Directories

mkdir test_dir
cd test_dir
touch example.txt
mv example.txt renamed_example.txt
cd ..

The mkdir command creates a new directory named test_dir. The touch command creates an empty file. The mv command renames example.txt to renamed_example.txt.

2. Viewing File Contents

cat /etc/passwd
head -n 5 /etc/passwd
tail -n 5 /etc/passwd

The cat command displays the full file contents. The head command displays the first 5 lines, and the tail command displays the last 5 lines.

3. Searching for Patterns

grep root /etc/passwd

The grep command searches for lines containing the word root in /etc/passwd.

4. Zipping and Unzipping

zip -r test_dir.zip test_dir
mkdir unzipped_dir
unzip test_dir.zip -d unzipped_dir

The zip command compresses the directory, and the unzip command extracts it into unzipped_dir.

5. Downloading Files

wget -O sample.txt https://example.com/

The wget command downloads content from a URL and saves it as sample.txt.

6. Changing Permissions

touch secure.txt
chmod 444 secure.txt
ls -l secure.txt

The chmod 444 command changes secure.txt permissions to read-only for everyone.

7. Working with Environment Variables

export MY_VAR="Hello, Linux!"
echo $MY_VAR

The export command creates an environment variable, and echo displays its value.
